# 💬 Real-Time Chat Application

A full-stack **MERN chat application** built with **React.js, Tailwind CSS, Node.js, Express.js, MongoDB, and WebSockets (Socket.io)**.  
This project demonstrates your ability to build **real-time communication systems** with responsive design and modern UI/UX.

---

## 🚀 Features
- **Real-Time Messaging**
  - Instant message delivery using WebSockets (Socket.io).
  - Own messages aligned to the right, others aligned to the left.
  - Auto-scroll to latest message.

- **User Interface**
  - Clean, responsive chat bubbles styled with Tailwind CSS.
  - Avatars and usernames displayed alongside messages.
  - Timestamp shown for each message.

- **Authentication**
  - User login and registration system.
  - Secure session handling with JWT.

- **Responsive Design**
  - Mobile-first layout with adaptive scaling.
  - Flexbox alignment ensures consistent UI across devices.

---

## 🛠️ Tech Stack
- **Frontend**: React.js, Tailwind CSS  
- **Backend**: Node.js, Express.js  
- **Database**: MongoDB  
- **Real-Time Communication**: WebSockets (Socket.io)

## ⚡ Getting Started

### Prerequisites
- Node.js and npm installed
- MongoDB running locally or on a cloud service

### Installation
```bash
# Clone the repository
git clone https://github.com/Arin-Yadav/Chat-App.git

# Navigate into the project folder
cd chat-app

# Navigate to frontend 
cd frontend

# Install dependencies
npm install

# Navigate to backend 
cd backend

# Install dependencies
npm install

# Start the development server
npm run dev
