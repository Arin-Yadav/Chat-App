# Real-Time Chat Application

A full-stack **MERN chat application** built with **React.js, Tailwind CSS, Node.js, Express.js, MongoDB, and WebSockets (Socket.io)**.  
This project demonstrates my ability to build **real-time communication systems** with responsive design and modern UI/UX.

---

## Features

- **Real-Time Messaging**
  - Instant message delivery using WebSockets (Socket.io).

- **User Interface**
  - Clean, responsive chat layout styled with Tailwind CSS.
  - Own messages aligned to the right, others aligned to the left.
  - Auto-scroll to latest message.

- **Authentication**
  - User login and registration system.
  - Secure session handling with JWT.

- **Responsive Design**
  - Mobile-first design with adaptive layouts.
  - Flexbox alignment ensures consistent UI across devices.
  - Clear separation of sender vs receiver messages.
  - Consistent card styling for chat bubbles.

---

## Tech Stack

- **Frontend**: React.js, Tailwind CSS
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **Real-Time Communication**: WebSockets (Socket.io)

---

### This project demonstrates:

- **Real-time communication** using WebSockets.
- **Responsive UI/UX design** with Tailwind CSS.
- **Integration of frontend and backend** for seamless communication.

## Getting Started

### Prerequisites

- Node.js and npm installed
- MongoDB running locally or on a cloud service

### Installation

```bash
# Clone the repository
git clone https://github.com/Arin-Yadav/Chat-App.git

# Navigate into the project folder
cd chat-app

# Navigate to frontend
cd frontend

# Install dependencies
npm install

# Navigate to backend
cd backend

# Install dependencies
npm install

# Start the development server for both frontend and backend
npm run dev
```
